# Front VTOL artwork

`harrier_front_generated.png` was generated with the built-in imagegen tool on
2026-09-16. Prompt: "Create a single tiny videogame sprite: a British Harrier jump jet viewed EXACTLY head-on, hovering in VTOL, landing gear extended. Strict bilateral symmetry, wings fully horizontal and very wide, central dark cockpit, green olive fuselage with restrained pale grey highlights, three visible black landing wheels below, central nose wheel and two outrigger wheels. Authentic very simple Amiga 1980s pixel art, not realistic or detailed. Design on an EXACT 16 columns by 8 rows logical pixel grid, upscale each logical pixel to an equal solid square, no subpixel details, no antialiasing, no outlines outside grid. The aircraft fills almost all 16x8 canvas with minimal transparent margin; silhouette should remain readable reduced to 16x8 pixels. Landscape canvas 2:1 aspect ratio. Truly transparent background. Only transparent, black, white/light grey, dark forest green, medium olive green, pale grey green. No text, no platform, no scenery, no shadow, no exhaust clouds. This will be reduced to a 16x8 attached hardware sprite in an existing Amiga game. Save as PNG."

The generated source is converted offline using BOX downsampling to 16x8,
retaining alpha (threshold 24/255 preserves thin fins/wheels), then nearest
colour in game palette indices 8/11 for green-dominant pixels and
2/3/4/10 for neutral pixels, preserving the aircraft colour at tiny size. Pen 0 remains transparent.
`../harrier_front_16x8.png` is the authoritative editable indexed master.
The packer maps its colours to fixed CPC+ attached-sprite pens 1..12.

Reverse Harrier and helicopter variants are exact deterministic mirrors of
existing masters, generated by the asset packer. Their palettes and dimensions
are unchanged. Both helicopter rotor frames are pre-shifted in both directions;
there is no per-frame pixel reversal on the 68000.
