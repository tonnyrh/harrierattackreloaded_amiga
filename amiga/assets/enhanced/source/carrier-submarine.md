# Native submarine artwork

Masters: carrier_submarine_32x8.png and carrier_ballistic_8x16.png, indexed
16-colour OCS palette with pen 0 transparent. Native pixel silhouettes use
neutral hull colours, a periscope and red/grey missile with yellow exhaust.
The packer emits four hull tiles and two missile tiles per vertical direction.
Masters remain editable; the build never regenerates them from source shapes.

Validation (2026-09-27): both profiles valid, 16-colour tile geometry, exact
32x8 and 8x16 dimensions. Local reports: .tmp/submarine-validation.json and
.tmp/ballistic-validation.json. Enlarged visual inspection: .tmp/submarine-preview.png.
